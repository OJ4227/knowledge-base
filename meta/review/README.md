# meta/review/

Destructive or structural changes the agents propose but must not apply on their own:
note merges, deletions, section restructures, non-trivial concept rewrites, enum changes.

One file per ISO week: `YYYY-WW.md`. Each item is a checklist entry with the proposed
change, the reason, and the affected notes. The owner applies or declines. Declined
link/merge proposals are copied to `meta/rejected-links.md` so they are not re-proposed.
